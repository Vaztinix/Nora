Privacy Policy

1. Privacy-First Design

Nora is designed with privacy as a core principle. The system only processes the minimum data necessary for functionality.

2. Operational Data

The system may store limited operational information required to function. This includes server identifiers, configuration settings, and command usage triggers.

3. Server Configuration Data

Configuration settings may include enabled features, configured channels, role identifiers, moderation settings, and leveling configuration information.

4. Message Processing

Message content may be temporarily processed for moderation filters or AI context. This processing occurs in memory and is not permanently stored unless a specific feature requires it.

5. Leveling System Data

When the leveling system is enabled, Nora may record user activity indicators such as message events or interaction counts to calculate progression.

6. Join Event Processing

When a server enables the welcome system, Nora listens for member join events to generate welcome messages.

7. Data Isolation

Each server's data is isolated. Data generated in one server is never shared with or visible to other servers.

8. Data Sharing

Nora does not sell, rent, or distribute server data to third parties. Data collected is used solely for operating the service.

9. Data Retention

Data is retained only as long as necessary for the feature that generated it. Removing Nora from a server deletes configuration data associated with that server.

10. Security Practices

Reasonable security practices are implemented to protect configuration data from unauthorized access.

11. Policy Updates

This policy may be updated periodically as the system evolves. Updated versions will be published on the Nora website.
